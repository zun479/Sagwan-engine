## 설치

1. 아래 **Assets**에서 `WikiHub-Setup-버전.exe`를 내려받아 실행합니다.
2. 설치 폴더를 고르고 [설치]를 누릅니다. 관리자 권한은 필요 없습니다.
3. 마지막 화면에서 [Wiki Hub 실행]을 체크한 채 [마침]을 누릅니다.

> 아직 코드 서명이 없어 처음 실행할 때 Windows가 "PC 보호" 창을 띄울 수 있습니다. [추가 정보] → [실행]을 누르세요.
> 받은 파일이 맞는지는 `SHA256SUMS.txt`의 값과 비교해 확인할 수 있습니다 (PowerShell: `Get-FileHash 파일이름`).

Windows 10/11, Microsoft Edge(기본 설치됨)가 필요합니다.

## 파일

- `WikiHub-Setup-*.exe` — Wiki Hub 설치 프로그램
- `sagwan-engine-*.zip` — 위키 엔진 소스 (Wiki Hub가 배포에 사용)
- `SHA256SUMS.txt` — 체크섬
